ELDRADO complete source + visual assets bundle

index.html
  Original ELDRADO v1.0 project HTML from ELDRADO_v10_GitHub.

assets/background/
  Existing field background image files. These are source references; eldorado_bg_clean.png still contains field UI/character artwork and is NOT a clean battle-only background.

assets/characters/
  Original Fel and Alice character sheets and related setting references.
  Fel canonical appearance: black-haired human male, dark armor/cloak, twin blades.
  Alice canonical appearance: silver-haired human woman, blue-and-white outfit, light/holy healing and resonance/link support.
  Do not reinterpret Alice as a vampire. Do not add species/lore not stated in the character sheets.

assets/enemy/
  mob_placeholder.svg is only a layout placeholder, not an approved canonical MOB design.

assets/ui/
  Prior SVG layout placeholders. They are not final character art.

assets/reference/
  Generated battle UI concept images for visual reference only. They are flattened composites and must NOT be used as the layered game background or as individual character sprites.

Layer target architecture (5 independent layers):
1. Clean battle background only (no characters, no UI)
2. Fel sprite
3. Alice sprite, with normal and link-state variants
4. MOB sprite
5. HTML/CSS battle interface

Important: This bundle preserves the original HTML and gathers the relevant source images. It does not claim that final separated sprites or a clean battle background have been completed.
