# ELDRADO v1.0 prototype

- `index.html`: HTML5 field and battle prototype.
- The six-element affinity master table is included in JavaScript:
  - Fire (火), Water (水), Wind (風), Earth (土), Holy (聖), Dark (闇)
- Damage baseline: `max(1, floor((ATK - DEF) * affinity))`.
- Element multipliers follow the user-approved 6×6 table.

Upload the contents of this folder to the repository root. GitHub Pages uses `index.html`.
